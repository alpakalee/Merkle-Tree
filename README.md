# Mini Git: 머클트리로 보는 파일 기록

4개 파일을 수정하고 저장할 때 해시가 바뀌는 경로와 이전 기록을 보여주는 웹 앱.

1. [처음 시작하기](docs/START_HERE.md): Git·GitHub·머클트리 그림, 기본 명령, 학습 링크
2. [프로젝트 설계](docs/PLAN.md): 기능 범위, 파일 구조, 두 작업 영역, 일정
3. [작은 이슈](docs/ISSUES.md): 8주 × 4개 작업, 각 작업의 완료 조건

진행 순서: 처음 시작하기 → 해당 주의 이슈 1개 → 결과 확인 → 작은 Git 커밋.
